<h1>Trueketeo - Digital Barter Platform</h1>

Trueketeo is a platform that aims to give a useful life to the objects we no longer need, in a world where everything has a price. It offers an inclusive, ecological, and sustainable alternative.  

We promote sustainability and environmental awareness, showing that there are alternatives to excessive consumption. We encourage exchanging what you already have, strengthening mutual aid networks, and giving a second life to objects that would otherwise become waste.  

Our project brings together everything we’ve learned: technical knowledge applied to a product with real purpose and user-oriented design. It required deep collaboration, building on existing code, and constant adaptation.  


<h2>🛠️ Technologies Used</h2>

- **Frontend:** React.js, HTML, CSS, Bootstrap  
- **Backend:** Python, Flask, JWT, SQLAlchemy  
- **Database:** PostgreSQL / MySQL / SQLite (configurable)  
- **Tools:** Pipenv, Node.js (v20), Webpack  


<h2>📜 Main Features</h2>

- Digital barter system to promote a sustainable collaborative economy.  
- Secure authentication using JWT.  
- RESTful API built with Flask.  
- Database management with SQLAlchemy.  
- Environment variable configuration for flexible setup.  
- Easy deployment on Render.com and Heroku.  
- Frontend management with React and Bootstrap for a responsive interface.
